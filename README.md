A lightweight online chat alternative in just two files! 

### Features:
 - Room creation
 - Room join/leave
 - Voice chat
 - Screen share
 - Message delete
 - Emoji react
 - Emoji Palette
 - @Mentions
 - Notifications
 - Link previews
